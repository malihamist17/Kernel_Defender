Why the differences matter

    

      Socket — fastest here because Unix domain sockets skip network stack overhead; the kernel just copies bytes between two processes.

      Pipe — similar to socket but simpler; the kernel manages a small buffer.

      Shared Memory — no kernel copying at all; both processes map the same physical pages. Wins for large data.

      Queue — pipe + internal lock + buffer management; safe but slow.
